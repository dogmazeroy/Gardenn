INCONNU CINEMA — v3 DIRECTOR'S CUT

Remake completo da interface, mantendo o catálogo de 38 filmes.

Principais mudanças:
- Home cinematográfica full-screen com filme do dia.
- Cor/acento da interface calculada automaticamente a partir da capa de cada filme.
- Seções de curadoria ("Salas da cinemateca") em vez de só uma grade.
- Busca global por título, diretor, gênero e ano, com ranking simples de relevância.
- Grade renovada com ações rápidas, CC, favoritos, vistos, nota e progresso.
- Dossiê de filme em tela cheia com sinopse, nota, anotação, relacionados e fonte.
- Player teatro para Google Drive, OK.ru e vídeo direto.
- Letterboxd por filme.
- Assistente de Rave por filme: copia a fonte e abre o Rave.
- Caderno com estatísticas, progresso da coleção, décadas, últimos vistos, exportar/importar.
- Links diretos para filmes usando #movie=<id>.
- Atalhos: / busca, R aleatório, S caderno, Esc fecha.
- Interface mobile refeita.
- Projeto estático pronto para GitHub + Vercel.

Limitação intencional:
A criação de uma sala do Rave exige a conta/app do usuário; o site prepara a fonte e abre o serviço, mas não simula uma criação de sala que não ocorreu.
